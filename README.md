### Overview
This project is a lightweight, high-performance portfolio landing page tailored for the DACH (Germany, Austria, Switzerland) tech market. It is designed to provide a fast, accessible, and professional first impression for recruiters and potential clients.

### Features
*   **Hero Section:** Impactful introduction with a clear call-to-action.
*   **Skills Showcase:** Organized grid layout to highlight technical expertise.
*   **Project Gallery:** Responsive cards to display your professional work.
*   **Testimonials:** Social proof section to build immediate trust.
*   **Contact Form:** Integrated form with robust client-side validation using Vanilla JavaScript.
*   **Performance Focused:** Zero-dependency architecture ensuring lightning-fast load times.
